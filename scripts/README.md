# Your scripts → 8–10 minute horror cartoons

Put a script here as a `.txt` file, then in GitHub go to **Actions → Horror long video (your script) → Run workflow**
and type the file name (for example `the_doll.txt`). The video is made in about 1–1.5 hours and published on
CreepyCartoonTales in the normal wide (16:9) YouTube format, with chapters and a thumbnail.

## How to write it

```
# The New House
I moved in on a Monday. The rent was suspiciously cheap.
The estate agent said the last tenant "just left". With all his furniture.

MUM: Did you lock the back door?
ME: Mum, I always lock the back door.

# The First Night
At three in the morning, someone knocked. From inside the wardrobe.
THE DOLL: You're in my bed.
```

- `# Something` starts a chapter (3 or more chapters become YouTube chapters).
- `NAME: line` is a character speaking. Each character gets their own natural voice.
  `ME` (or your hero's name) is the hero; MUM, DAD, GRANDMA, GRANDPA, ROOMMATE, FRIEND, SISTER, BROTHER and
  OFFICER are side characters; anything like THE DOLL, THE VOICE, IT, THE STRANGER is the villain.
- Everything else is narration, told by the hero in the first person.
- 8–10 minutes is about **1,200–1,500 words**.
- Keep it spooky-fun: no gore, no real people, no brands.

Your words are used exactly as written. The pictures (sets, faces, camera moves, what happens on which word) are
planned automatically.
